# T10.3 — `npm pack --dry-run` review

**Phase** P10 — Docs & the artifact · **Board** [`.claude/TASKS.md`](../TASKS.md) (status lives there)

## Goal

Look at the exact tarball that would be published, before anyone can publish it.

## Acceptance criteria

- `npm pack --dry-run` run from the repo root. **It stays `npm`** — this checks the
  registry's own tarball rules, not a package-manager preference (see
  [T0.6](T0.6-toolchain-decision.md)). Do not "convert it to bun".
- Contents are exactly: `dist/`, `README.md`, `LICENSE`, `package.json`. Nothing else.
- Specifically absent: `src/`, `test/`, `playground/`, `.claude/`, `docs/`, tsconfigs,
  `biome.json`, `vitest.config.ts`, `bun.lock`, `.github/`.
- Total size sanity-checked and noted below.
- The file list is recorded in "Where it stands" so a future release can diff against it.

## Stop

**Publishing requires the user's explicit go.** `npm pack --dry-run` is the ceiling for
autonomous work (ground rule 6). Do not run `npm publish`, `bun publish`, or set up a
release workflow that would.

## Where it stands

Run 2026-08-08 with `npm pack --dry-run` — still npm, deliberately, because this checks the
registry's own tarball rules rather than a package-manager preference. **Nothing was published**;
this is the ceiling for autonomous work.

```
name          fc-react-dnd
version       0.1.0
filename      fc-react-dnd-0.1.0.tgz

```

**Top-level entries: `dist`, `README.md`, `LICENSE`, `package.json`.** Nothing else — every
non-`dist/` file in the tarball is one of those three.

Specifically checked absent, and absent: `src/`, `test/`, `playground/`, `.claude/`, `docs/`,
`tsconfig.json`, `tsconfig.build.json`, `biome.json`, `vitest.config.ts`, `bun.lock`, `.github/`,
`bunfig.toml`.

`CHANGELOG.md` is **not** shipped, which matches this task's criteria. npm force-includes only
`package.json`, the README, and the licence regardless of `files`, and `files: ["dist"]` excludes
the rest. Worth knowing rather than discovering later: a future release that wants the changelog
in the tarball has to add it to `files` explicitly.

103 files is 25 modules × 4 emitted artefacts (`.js`, `.js.map`, `.d.ts`, `.d.ts.map`) plus the
three top-level files — the same 1:1 mirror [T9.4](T9.4-build-and-package-checks.md) verified.

# T10.4 — Final `mihai-coding-standards` sweep

**Phase** P10 — Docs & the artifact · **Board** [`.claude/TASKS.md`](../TASKS.md) (status lives there)

## Goal

Every task ends with the standards' closing checklist against its own diff. This task runs
it against the **whole** diff, where the cross-file problems live — the duplicated helper in
two internal modules, the two names for the same concept, the constant that drifted.

## Acceptance criteria

- Load the `mihai-coding-standards` skill and walk its closing checklist over the complete
  diff, not a sample.
- Naming: one concept, one name, package-wide. Public option/result types unique
  (`UseDraggableOptions`, `DndProviderProps`, …); the `Props` shorthand only on
  non-exported internal components.
- No `any` anywhere. Type-only imports consistent with `verbatimModuleSyntax`.
- No bare literals in logic — every tunable is a named constant next to its use.
- DRY across `src/internal/*`: no helper implemented twice, no re-export hub anywhere
  (ground rule 4).
- Every module that needs `'use client'` has it; every pure module still doesn't
  (`collision`, `types`, `internal/geometry`, `tree`, `internal/announcements`,
  `internal/list-projection`).
- Relative imports all carry `.js`.
- Perf invariants 1–9 and accessibility invariants 1–4 each traceable to a test that would
  fail if broken. **Any invariant with no such test is a finding** — record it and open a
  task rather than quietly asserting it holds.
- `bun run verify` green at the end.

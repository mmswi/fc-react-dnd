# T0.3 — The split task board

**Phase** P0 — Governance · **Board** [`.claude/TASKS.md`](../TASKS.md) (status lives there)

## Goal

A board that stays readable as it grows. `.claude/TASKS.md` is a table of contents —
one line per task, carrying the status. Each task's detail lives in its own small
file under `.claude/tasks/`, so opening a task means reading one page, not scrolling
a 400-line monolith.

## Test first

Not applicable — no code.

## Acceptance criteria

- Board lives under `.claude/`, not the repo root; the old root `TASKS.md` is gone.
- `.claude/TASKS.md` lists every task as `- [ ] [T<phase>.<n>](tasks/<file>.md) — title`.
- Every task id in the TOC has exactly one file in `.claude/tasks/`, and every file
  in `.claude/tasks/` has exactly one TOC line. No orphans in either direction.
- Task files carry goal / test-first / acceptance criteria / files / where-it-stands,
  and **no** status field or checkbox criteria.
- File naming is `T<phase>.<n>-<kebab-slug>.md`, flat (no per-phase subdirectories) —
  ordering comes from the TOC, so lexical sort of `T10.1` vs `T2.1` is irrelevant.
- `CLAUDE.md` § "Task workflow" documents all of the above.

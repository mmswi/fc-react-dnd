# T5.2 — `src/keyboard-sensor.ts`

**Phase** P5 — Sensors · **Board** [`.claude/TASKS.md`](../TASKS.md) (status lives there)

## Goal

A first-class keyboard drag — not an afterthought (accessibility invariant 1). The design
that makes this cheap: arrow keys produce a **transform**, exactly like a pointer would,
so keyboard drags flow through the same collision and the same tree-depth math rather than
a parallel code path.

## Test first

Red tests before implementation:

- Space and Enter both pick up a focused draggable; a second press drops it.
- Arrow keys move to the **nearest droppable in that direction**, using
  `findDroppableInDirection` from [T2.2](T2.2-geometry.md) — including the case where
  there is nothing in that direction (stay put, don't wrap, don't jump across the page).
- **The targeting query includes measure-only rects** ([T3.1](T3.1-store.md)): tree rows are
  not droppables, but keyboard vertical navigation must still step through them. Collision
  stays droppables-only; targeting reads the whole rect cache.
- **Tree reachability composes from here** (§ A7 F9): vertical steps move through row
  positions, ArrowLeft/Right walk the depth ladder via the same ±indent transforms, and
  every legal tree outcome must be reachable — the invariant test lives in
  [T8.2](T8.2-use-tree-drop.md); this sensor must not hard-code any tree knowledge to make
  it pass.
- **ArrowLeft / ArrowRight double as ±indent**, emitting a horizontal transform step. This
  is the seam that gives the tree its keyboard depth control in
  [T8.2](T8.2-use-tree-drop.md) — assert the transform, not a tree-specific side effect,
  so the sensor stays tree-agnostic.
- Escape cancels; **blur cancels** (a drag must not survive the user tabbing away).
- `scrollIntoView` is called when the target changes, so the keyboard drag stays visible.
- Teardown after drop, cancel, and unmount-mid-drag leaves no listener behind.

## Acceptance criteria

- Exports `keyboardSensor` + `KeyboardSensorOptions`; subpath `fc-react-dnd/keyboard-sensor`.
- Activation keys `preventDefault` (perf invariant 6) so Space doesn't scroll the page
  mid-drag.
- Indent step is a named constant, overridable through options.
- Emits the same announcements pipeline as the pointer path
  ([T6.3](T6.3-accessibility-internals.md)).
- `'use client'` at the top.

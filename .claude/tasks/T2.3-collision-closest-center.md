# T2.3 — `src/collision.ts`: `closestCenter`

**Phase** P2 — Core primitives · **Board** [`.claude/TASKS.md`](../TASKS.md) (status lives there)

## Goal

The one collision strategy this library ships (scope lock, [T0.5](T0.5-scope-lock.md)).
Public subpath `fc-react-dnd/collision`. Pure and directive-free so it stays
server-importable.

## Test first

Red tests before implementation:

- Picks the droppable whose centre is nearest the active rect's centre.
- Equidistant candidates resolve **deterministically by registration order**, not by
  object iteration order — assert the same input twice yields the same winner, and that
  reversing the candidate list does not flip a genuine winner.
- Empty candidate list returns nothing (not a crash, not a bogus id).
- A disabled droppable passed in **is** considered — filtering disabled entries is the
  caller's job, and a test should pin that boundary so nobody "fixes" it by adding a
  `disabled` check inside the math.

## Acceptance criteria

- Exports `closestCenter` implementing the `CollisionDetection` type from
  [T2.1](T2.1-public-types.md).
- No DOM access, no React, no `'use client'` — it operates on the rects it is handed.
- The disabled-droppable decision lives in the caller (the store's args), and the
  boundary is documented in a comment where a reader would otherwise be tempted.
- Exactly one strategy exported. Additional strategies are a Backlog item.

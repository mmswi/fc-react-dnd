## The decision

| Job | Tool | Replaces |
| --- | --- | --- |
| Package manager, script runner, workspaces | **bun** (1.3.5 local) | pnpm |
| Lint + format + import sorting | **Biome** (2.x, latest 2.5.7) | ESLint + `typescript-eslint` + `eslint-plugin-react-hooks` + Prettier + `eslint-config-prettier` |
| Test runner | **Vitest** (jsdom) | — kept |
| Build | **tsc** per-file emit | — kept, no bundler |

Notes that cost time if forgotten:

- **`bun test` is not `bun run test`.** `bun test` invokes Bun's own runner, ignores
  `vitest.config.ts`, and produces failures that look like product bugs. Every doc,
  script, and CI step says `bun run test`.
- **Vitest stays** on purpose. The suite depends on `vitest.config.ts`, jsdom, and
  `vi.useFakeTimers({ toFake: ['requestAnimationFrame'] })`. Swapping to `bun:test`
  is a Backlog item, not a P1 side effect.
- **Workspaces** move from `pnpm-workspace.yaml` into `"workspaces": ["playground"]`
  in `package.json`. `bun run --filter <pkg> <script>` matches the workspace
  **package name**, not the directory — there is no `--cwd` on `bun run` in 1.3.5.
- **`npm pack --dry-run` stays npm.** It is a check against the registry's tarball
  rules, not a package-manager preference.
- **Biome is one command.** `biome check` runs lint + format + import sorting;
  `biome check --write` fixes. Don't mirror ESLint's separate `lint`/`format` split.

## The locked scope

**In:**

- Sortable list.
- Pointer + keyboard sensors.
- Exactly **one** collision strategy: `closestCenter`. The `CollisionDetection` type
  stays public so consumers can plug in their own; the library ships one.
- A drag overlay.
- **The flagship:** first-class tree drag-and-drop — drop-into vs drop-between, depth
  projection during the drag, cycle prevention — as pure, Node-tested functions.
  The differentiator, verified in [`ANALYSIS.md`](../ANALYSIS.md) § A2: every
  general-purpose React DnD library reports a *gesture relative to one row* and stops;
  this one returns the *outcome* — `(parentId, index, depth)` clamped against both
  neighbours, with the active subtree excluded so cycles are unrepresentable.

**Deliverables around the code:**

- A StrictMode-clean demo.
- A React Profiler render-count comparison against dnd-kit.
- A technical blog post — **the blog post is the actual artifact; the library is the
  evidence for it.**

**Out (see the Backlog in the TOC):** cross-list/kanban moves, extra collision
strategies, drop animation, RTL, virtualization recipes.

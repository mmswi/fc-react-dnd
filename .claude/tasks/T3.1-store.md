# T3.1 — `src/internal/store.ts`

**Phase** P3 — Store & subscription layer · **Board** [`.claude/TASKS.md`](../TASKS.md) (status lives there)

## Goal

The heart of the library: a plain external store holding all drag state, created **per
`DndProvider` instance** — never module-level, so it is SSR-safe and multi-provider-safe.
This is where the central performance claim is either true or false: rects are measured
once at drag start and every subsequent move is pure arithmetic against the cache.

## Test first

The store is synchronous by design and needs no React and no frame control, so it can be
driven directly. Red tests before implementation, one behaviour at a time:

- **Registration never notifies.** Subscribe, register and unregister a draggable and a
  droppable, assert the subscriber was called zero times (perf invariant 5).
- **Rects measured once.** Count measurement calls across `beginDrag` + N `updateDrag`
  calls; assert measurement happened once, not N+1 times (perf invariant 1).
- **Dirty flag.** After a scroll/resize signal, the next update re-measures — and only
  the next one.
- **Stale session token.** A `DragSession` captured before `endDrag` becomes a no-op
  afterwards: calling `move` / `setTransform` / `end` on it changes nothing and notifies
  nobody.
- **Events fire before state reset.** An `onDragEnd` listener reading active/over during
  the callback sees the drag that just ended, not a cleared state. Same for cancel.
- **Monitor fan-out** reaches every listener; unsubscribing one leaves the others intact.
- **Immutable state object** — every notifying transition produces a new state reference,
  which is what makes the WeakMap memoization in [T7.1](T7.1-list-projection.md) and
  [T8.2](T8.2-use-tree-drop.md) sound.

## Acceptance criteria

- A factory function, not a class (per the standards).
- Registries for draggables and droppables; register/unregister mutate without notifying.
- Lifecycle: `beginDrag`, `updateDrag`, `endDrag`, `cancelDrag`.
- `DragSession` handed to sensors on activation, guarded by a session token so a stale
  session cannot resurrect a finished drag.
- Droppable-rect cache: batched reads at `beginDrag`, re-measured lazily via the dirty
  flag — **no DOM reads in the move path** (perf invariant 1, 2).
- Collision runs against the cache on every move, with disabled droppables filtered here
  (the boundary [T2.3](T2.3-collision-closest-center.md) deliberately leaves to the caller).
- Complete teardown on end/cancel — no per-interaction state survives (perf invariant 7).
- Named constants for any tunable; no `any`.

# T2.2 — `src/internal/geometry.ts`

**Phase** P2 — Core primitives · **Board** [`.claude/TASKS.md`](../TASKS.md) (status lives there)

## Goal

Pure rect math, no DOM and no React, so it can be tested exhaustively in milliseconds.
Everything expensive in this library reduces to arithmetic on cached rects; this is that
arithmetic.

## Test first

Red tests before implementation, table-driven on hand-computed rects:

- Centre of a rect; translating a rect by a `Translate`.
- Distance between centres — including the degenerate zero-distance case.
- `findDroppableInDirection` (keyboard targeting): from a start rect and a direction,
  pick the nearest candidate **in that direction**. Cases that must be red first:
  candidates strictly behind the direction are excluded; a candidate directly ahead beats
  a closer one off-axis (axis-weighted score); no candidate ahead returns nothing rather
  than the nearest anywhere; ties resolve deterministically.

## Acceptance criteria

- Pure functions only — no `document`, no `window`, no React import, no `'use client'`.
- `findDroppableInDirection` filters by direction first, then scores with the movement
  axis weighted more heavily than the cross axis, so keyboard navigation feels like
  "next item over" rather than "nearest thing on screen".
- Deterministic tie-breaking (stable by registration order), asserted by a test.
- Named constants for any weighting factor — no bare literals in the scoring, per repo
  conventions.
- Feeds both [T5.2](T5.2-keyboard-sensor.md) and [T2.3](T2.3-collision-closest-center.md)
  without either importing DOM code.
